Comprendre les codes d'erreur

Les chaudières modernes sont équipées de systèmes d'autodiagnostic qui affichent des codes d'erreur lorsqu'un problème est détecté. Ces codes vous aident à identifier rapidement la nature du problème et à prendre les mesures appropriées.

Ci-dessous, vous trouverez une liste des codes d'erreur courants pour les principales marques de chaudières. Si votre code n'est pas listé ou si vous avez besoin d'assistance, n'hésitez pas à nous contacter.

Que faire en cas de code d'erreur ?

  • Noter le code d'erreur qui s'affiche sur votre chaudière
  • Consulter le manuel d'utilisation pour comprendre la signification
  • Vérifier les éléments de base comme la pression d'eau et l'alimentation
  • En cas de doute, ne pas tenter de réparer vous-même
  • Contacter un professionnel pour éviter d'aggraver le problème
